## Setup Instructions

To explore the **CrimeWatch DC** dashboard, no special installation is required apart from a code editor or browser with live preview support. The project is built entirely with HTML, CSS, JavaScript, and D3.js, so it runs locally in the browser without any backend.

### To get started:

1. Unzip the project folder.
2. Open the folder in **Visual Studio Code** (or any code editor that supports live server functionality).
3. Ensure the **Live Server** extension is installed in VS Code.
4. Right-click on `home.html` and select **"Open with Live Server"**.
5. The site should automatically open in your default browser.

All data and preprocessing files are included in the `data/` folder, and all visualizations are implemented using D3.js. No internet connection is required, except for loading the D3 library, which is imported via CDN in each HTML file.
